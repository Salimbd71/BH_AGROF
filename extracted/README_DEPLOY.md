# BH Agro - দুই সাইট (SR + Admin), একই ডাটাবেস

## ফাইল স্ট্রাকচার (যা নতুন/বদলেছে)
```
src/
  apps/
    types.ts            রুলসের ফরম্যাট
    sr/rules.ts         ★ এসআর সাইটের রুলস (কোন পেজ, কী লিখতে পারবে)
    admin/rules.ts      ★ অ্যাডমিন সাইটের রুলস
  config/
    appMode.ts          বিল্ড mode (sr/admin) দেখে সঠিক রুলস বেছে নেয়
    firebase.ts         Firebase কনফিগ (env থেকে)
  modules/              দুই সাইটের শেয়ার্ড কোড (আগের মতোই)
  main.ts               শেয়ার্ড কন্ট্রোলার
```
রুলস বদলাতে চাইলে শুধু `apps/sr/rules.ts` বা `apps/admin/rules.ts` খুলুন।

## দুই সাইটের পার্থক্য
| | SR সাইট | অ্যাডমিন সাইট |
|---|---|---|
| লগইন | শুধু SR | শুধু Admin |
| পেজ | home, customers, order_booking, products, my_orders, reports | সব |
| ডাটাবেসে লিখতে পারে | orders, customers, products | সব (srs, admins সহ) |
| ডাটাবেস সেটিংস বাটন | নেই | আছে |
| প্রথম অ্যাডমিন তৈরি বাটন | নেই | আছে |
| সার্চ ইঞ্জিন | আসবে | noindex |

## লোকালে চালানো
```
npm install
cp .env.example .env.local     # Firebase মান বসান
npm run dev:sr                 # http://localhost:3000
npm run dev:admin              # http://localhost:3001
```

## ডিপ্লয় (GitHub-এ কোড পুশ করার পর, একই রিপো থেকে দুটো সাইট)

### Cloudflare Pages (সুপারিশ)
প্রতিটার জন্য: Workers & Pages → Create → Pages → Connect to Git → একই রিপো
- SR সাইট:    Build command `npm run build:sr`,    Output directory `dist/sr`
- Admin সাইট: Build command `npm run build:admin`, Output directory `dist/admin`

### Netlify
Add new site → Import from Git → একই রিপো, দুইবার:
- SR সাইট:    Build command `npm run build:sr`,    Publish directory `dist/sr`
- Admin সাইট: Build command `npm run build:admin`, Publish directory `dist/admin`

### দুই সাইটেই Environment variables (একই মান)
```
VITE_FIREBASE_API_KEY
VITE_FIREBASE_AUTH_DOMAIN
VITE_FIREBASE_DATABASE_URL
VITE_FIREBASE_PROJECT_ID
```
env বদলালে আবার ডিপ্লয় (Redeploy) করতে হয়।

ফলাফল: দুটো আলাদা লিংক, যেমন `bhagro-sr.pages.dev` আর `bhagro-admin.pages.dev`।

## মনে রাখার বিষয়
- ডাটাবেস এখনও Test Mode (সবার জন্য খোলা)। আসল ডাটা তোলার আগে Rules ঠিক করুন।
- এসআর সাইট ডাটাবেসের `srs`/`admins` অংশ কখনো ওভাররাইট করে না।
- "Reset Local" এখন ক্লাউড ডাটা মোছে না, শুধু ওই ডিভাইসের ক্যাশ খালি করে।
- এসআর ডিলিট এখন "সফট ডিলিট": লগইন বন্ধ হয়, কিন্তু অর্ডার/বিক্রি থাকে এবং রিপোর্টে "(প্রাক্তন)" লেবেলে দেখায়। অ্যাডমিন প্যানেলের "প্রাক্তন এসআর" তালিকা থেকে "আবার চালু করুন" করা যায়।
- নতুন এসআর আইডি সবসময় এ পর্যন্ত ব্যবহৃত সর্বোচ্চ নম্বরের পরেরটা হয়; ডিলিট করা বা অর্ডারে ব্যবহৃত আইডি আর ফেরত আসে না।
- ডিলিট করা এসআরের কাস্টমাররা কাস্টমার তালিকায় "প্রাক্তন এসআর, নতুন দিন" দেখায়; অন্য এসআরকে অ্যাসাইন করুন।
- এসআর সাইটে অ্যাডমিন লগইন, ট্যাব, ডাটাবেস সেটিংস, অ্যাডমিন তৈরি, কিছুই নেই। অ্যাডমিন সাইট শুধু আলাদা লিংকে।
- এসআর সাইটের অর্ডার বুকিং: অর্ডার স্লিপ উপরে, স্লিপের ভেতরেই কাস্টমার (ট্যাপ করলে বদলানো যায়), নিচে প্রোডাক্ট লিস্ট। প্রোডাক্ট পেজও লিস্ট আকারে।
- সার্চ, ডিসকাউন্ট ও নোট লেখার সময় এখন শুধু প্রয়োজনীয় অংশ আপডেট হয়, ইনপুট বক্স নতুন করে আঁকা হয় না, তাই কীবোর্ড বন্ধ হয় না।

## PWA (অ্যাপের মতো ইনস্টল ও অফলাইন)
- দুই সাইটই আলাদা PWA: `BH Agro SR Portal` (সবুজ আইকন) ও `BH Agro Admin Panel` (বেগুনি "ADMIN" আইকন)।
- `npm run build:sr` / `build:admin` নিজে থেকেই `manifest.webmanifest` ও `sw.js` বানায় (scripts/pwa-plugin.ts)।
- ইনস্টল: Android/Chrome ও ডেস্কটপে উপরে "ইনস্টল" বার আসে; iPhone-এ Share → Add to Home Screen।
- অফলাইন: একবার অনলাইনে খুললে অ্যাপ, আইকন ও CDN স্ক্রিপ্ট ফোনে ক্যাশ হয়। নেট ছাড়া অ্যাপ খোলে, অর্ডার ফোনে সেভ হয়,
  নেট এলে নিজে থেকে জমা হয়। অফলাইনে নেওয়া নতুন অর্ডার/কাস্টমার ক্লাউডের ডাটার সাথে জুড়ে যায় (অ্যাডমিন যা মুছেছে তা ফেরে না)।
- নতুন ভার্সন ডিপ্লয় করলে ব্যবহারকারী উপরে "আপডেট করুন" বার দেখে।
- Service worker শুধু প্রোডাকশন বিল্ডে চলে (`npm run dev` এ নয়)। PWA পরীক্ষা: `npm run build:sr` তারপর `npx vite preview --mode sr`।
- অর্ডার আইডির ফরম্যাট এখন `BHA-ORD-YYYYMM-<SR আইডি>-<ক্রম>` (যেমন BHA-ORD-202611-SR01-003), যাতে একাধিক এসআর বা অফলাইনে আইডি না মিলে।

## মোবাইল ও ডেস্কটপ
- মোবাইল: অর্ডার স্লিপ উপরে, নিচে ভাসমান "মোট হিসাব" বার (স্লিপ স্ক্রিনের বাইরে গেলে আসে), ইনপুট ১৬px (iPhone-এ জুম হয় না)।
- ডেস্কটপ (বড় স্ক্রিন): অর্ডার বুকিংয়ে বামে প্রোডাক্ট লিস্ট, ডানে স্থির (sticky) অর্ডার স্লিপ; প্রোডাক্ট পেজে দুই কলাম। `/` চাপলে সার্চ বক্সে ফোকাস।
- কার্ট ফোনে সেভ থাকে (রিফ্রেশ/অ্যাপ বন্ধ করলেও থাকে), লগআউট করলে অন্যের কার্ট দেখা যায় না।
- অর্ডার জমা দেওয়ার আগে নিশ্চিতকরণ (কাস্টমার, আইটেম, মোট) দেখায়।
